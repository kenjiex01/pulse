## 09:15 — Auto-send memos when payroll is posted

**Why:** Late, undertime, and absent memos should go out automatically after posting a payroll batch, using each Memo Setup count threshold.

**Files:**
- `app/Services/TimekeepingMemoPayrollPostService.php`
- `app/Http/Controllers/PayrollTransactionController.php`
- `tests/Unit/TimekeepingMemoPayrollPostServiceTest.php`

**Summary:**
- After a successful batch post, each employee in the batch is checked for late, undertime, and absent violations in the pay period.
- A memo is sent per violation type when the count meets or exceeds the Count saved in Memo Setup (e.g. 3 lates → late memo).
- Types without a configured template are skipped; send failures are logged and surfaced in the post success message without blocking the post.
