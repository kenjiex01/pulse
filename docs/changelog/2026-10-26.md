## 14:42 — Dispute categories: Over Payment - Days / Over Payment - Overtime

**Why:** HR needs to file disputes in the payroll batch to recover overpaid days and overtime from a previous posted batch.

- `tests/Feature/PayrollDisputeTest.php`

**Summary:**
- New categories **OPD = Over Payment - Days** and **OPO = Over Payment - Overtime** in the batch Disputes tab (File Dispute) and the dispute upload.
- OPD: (paid basic hrs − actual basic hrs from entered Time In/Out) × hourly rate. Blank Time In/Out = absent → buong paid basic ng araw na iyon ang ibabawas.
- OPO: (paid OT min − actual OT min) × OT rate. Blank OT Start/End = walang OT na na-render.
- On Process/Reprocess these become **deduction** lines (new deduction types `DOPD` / `DOPO`, reference "Dispute", reference date = work date) instead of income lines; no duplicates on reprocess.
- Disputes tab / view modal show overpayments as negative "Amount to Deduct"; form label switches between Expected Pay and Amount to Deduct.
- Same-day conflict guard: Unpaid Days ↔ Over Payment - Days, Unpaid Overtime ↔ Over Payment - Overtime.
- Seeded `DOPD`/`DOPO` via `PayrollMaintenanceSeeder` (also in desktop reference seed chain).
- Tests: 3 new tests in `PayrollDisputeTest` (10 total pass); payroll/dispute/upload suite 176 pass (only pre-existing memo report preview failure); `npm run build` done.
