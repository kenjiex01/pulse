## 11:21 — Windows setup no longer stuck on “cannot be closed”

- `scripts/nsis/people360-firewall.nsh`
- `.env.example` (`NATIVEPHP_APP_VERSION=1.0.55`)

**Summary:**
- The Windows installer force-closes People360 and any helper still running from the People360 folder, then continues.
- It no longer treats a failed process search as “the app is still open.”

## 11:36 — Installer continues when the old uninstall fails

**Why:** 1.0.55 still showed “People360 cannot be closed” after the previous version’s uninstaller returned an error, even with no people360.exe running.

**Files:**
- `scripts/patches/patch-nsis-close-dialog.py`
- `scripts/build-desktop.sh`
- `.env.example` (`NATIVEPHP_APP_VERSION=1.0.56`)

**Summary:**
- If the old uninstaller fails, setup deletes the program folder and continues. Payroll data in AppData is left in place.
- A failed file copy overwrites the app files instead of asking the user to close People360 and click Retry.
