## 19:25 — Desktop speed: OPcache, boot-once bootstrap, debug off

**Why:** NativePHP serves pages with `php -S`, so every request re-booted Laravel and re-ran migrate + healing seeders. Measured ~100–190 ms of pure bootstrap per request on macOS SSD; far worse on Windows laptops with antivirus + SQLite.

**Files:**
- `config/uploads.php`
- `app/Providers/AppServiceProvider.php`
- `app/Services/DatabaseBackupService.php`

**Summary:**
- Enable OPcache in the bundled PHP via `ProvidesPhpIni` (`opcache.enable`, `enable_cli`, 192 MB, 20k files, revalidate every 60s) so PHP files are not recompiled on every request.
- `ensureDesktopDatabase()` writes `storage/app/.desktop-schema-state` (app version + migration file count) and skips migrate/heal/seed chain when it matches. First launch after install/update still runs the full chain. Boot cost drops from ~100 ms to ~6 ms per request.
- Force `app.debug=false` on desktop (bundled `.env` ships `APP_DEBUG=true`); override with `NATIVEPHP_DEBUG=1`.
- SQL restore now clears the schema, bootstrap, and govt-table markers so healing re-runs after a restore.
