## 08:31 — Faster People360 desktop startup

**Why:** The window stayed hidden while Electron rebuilt caches and booted PHP twice on every open.

**Files:**
- `app/Support/DesktopStartupProbe.php`
- `app/Providers/AppServiceProvider.php`
- `scripts/patches/patch-startup-speed.py`
- `scripts/build-desktop.sh`
- `tests/Unit/DesktopStartupProbeTest.php`

**Summary:**
- Desktop launch no longer runs `php artisan optimize` before the window. That step rebuilt config, routes, and every Blade view on each open.
- Leftover config and route caches are removed at launch so an old baked secret cannot block the window.
- `native:config` and `native:php-ini` results are reused for the same app version, and those two commands skip the database setup.
- People360 **1.0.43** installers: `dist/People360-1.0.43-arm64.dmg`, `dist/People360-1.0.43-setup.exe`.
