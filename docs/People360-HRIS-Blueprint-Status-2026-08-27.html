Desktop + Web · What already works · What is incomplete · What is not yet built

Date: 27 August 2026  |  Audience: Management, HR, and project stakeholders

Compares the Philippine HRIS Software Module Blueprint (28 modules) with People360 Desktop (pulse/) and People360 Web (Skolaris /people360 in iskolaris-fe + iskolaris-be). Combined = best of both. Planning guide only — not a legal review.

Snapshot — Combined (Desktop + Web)

Desktop is strongest for school payroll and timekeeping. Web is strongest for employee self-service, document review, attendance checker, and Job Order requests. Together they are still not a full hire-to-retire HRIS.

StatusCountMeaning
Ready0 of 28No module is complete vs the full blueprint.
Partial13 of 28Includes M16 (self-service) now that Web ESS exists.
Not yet built15 of 28Needs new design and development on both products.
  • Desktop: employees, payroll, time logs, BIR / SSS / PhilHealth / Pag-IBIG reports, faculty load pay.
  • Web: employee login, profile, document upload + HR review, attendance view, Job Order (WRF) + approvals.
  • Still missing on both: recruitment, leave filing/balances, contractors, discipline, full clearance/separation, live clock-in.

What already works well

On Desktop

Payroll

Pay periods, compute/post, OT / ND / holiday, payslips, register, BIR 1601-C / 2316 / Alphalist.

Government contributions

SSS, PhilHealth, Pag-IBIG tables and contribution reports; employee loans.

Timekeeping

Policies, shifts, holidays, time log upload, biometric pull, attendance edit, OT for payroll.

Employee records & faculty load

Faculty / staff / admin / hybrid; campuses; salary history; credentials; Skolaris load pull and faculty pay.

On Web (Skolaris People360)

Employee self-service (M16)

Login/OTP, dashboard, profile edit, own attendance & loading attendance, My Requests, request approvals.

Documents (M04)

Employee upload / mark N/A; HR document review (verify, remap type, approve/reject).

Attendance ops (M05)

Timekeeping (load-based), Attendance Checker, biometric log restore.

Local employees, faculty load PDFs, privacy & access

Restored desktop employees + sync APIs; faculty loading PDF module; privacy consent; users/roles; API keys; payroll backup restore (ops only).
